BugPin Options

Capture

When an annotation is saved, capture a full visible-tab screenshot and a cropped shot of the annotated element. Turn off to annotate without any images in the export.

Keeps the wider-context screenshot next to the tight element crop for each annotation. Has no effect if screenshots are off.

Console, network, step and navigation events are kept in a ring buffer of this size; the oldest events are dropped first once the limit is reached.

Privacy

Masks password field values, Authorization/Cookie/Set-Cookie headers, and strings that look like API keys, bearer tokens or JWTs before anything is stored. This is best-effort pattern matching, not a guarantee — unusual secret formats can still slip through, so review an export before sharing it.

After a successful export, copy the resulting folder's path so you can paste it straight into an AI agent or a ticket.
